### {% label 浮見堂公園 red %}

{% note info no-icon %}
位於洞爺湖北方湖畔的「浮見堂公園」，是一處私房的賞櫻景點。這裡沒有喧囂的商家與擁擠的人潮，只有悠閒散步與露營的人們。湖畔春意盎然、百花盛開，靜謐的氛圍令人身心舒暢。

### {% label ふきだし公園 (名水公園) green %}

{% note info no-icon %}
這裡被譽為「名水之鄉」。水源來自羊蹄山的雨雪，經過數十年滲透地下孕育而成，水質甘甜，常年水溫維持在 6.5 度左右，出水量驚人。
{% endnote %}

抵達公園後，我們迫不及待地品嚐了湧泉，冰涼透心。公園內的櫻花同樣處於盛開狀態，美得讓人流連忘返，更是女兒牛奶糖最愛盡情奔跑的地方。離開前，我們不僅裝滿了一大瓶山泉水準備回飯店泡咖啡，還買了用名水製作的特色布丁（有原味、咖啡等口味）大飽口福。
