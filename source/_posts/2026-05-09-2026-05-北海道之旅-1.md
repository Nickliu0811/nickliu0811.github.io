# 遊記與照片

## 第一天：降落新千歲機場，啟程

### {% label 北海道自駕去 purple %}

{% note info no-icon %}
這趟旅程我們捨棄了 TOYOTA 租車，改選在地租車公司。不僅車況與等級出乎意料的好，價格更是划算了三到四成，為這趟自駕遊開了個完美且精打細算的起頭！
{% endnote %}

![租車](https://lh3.googleusercontent.com/pw/AP1GczPBhPjHezbSnAAJK1qp2cExc0_jNgriXTSzf4byCTf7Vvc1tFijVoVUDGxf-5EtZ6730ZDZBsrkXSe58iOph1pgfAtGrFcpl2-9mUkPUf6e4fVAA9oe6Q28t94qPzOglMC3lc3FgarCFkfLedD5ilKcXA=w1824-h1026-s-no)

<br>

### {% label 霧雨中的不凍湖：支笏湖 purple %}

{% note success no-icon %}
中午於新千歲機場降落並在美食街迅速解決午餐後，我們隨即驅車前往首站——支笏湖。五月的北海道依舊帶著寒意，氣溫僅約 10 度，伴隨著陰雨綿綿與強風，湖面蒙上了一層迷濛的霧氣。考量到太太與孩子不想吹風受寒，我們僅短暫停留。這與我前次造訪時的清朗感受截然不同，但也別有一番北國的蕭瑟之美。
{% endnote %}

![不結凍的支芴湖](https://lh3.googleusercontent.com/pw/AP1GczPs-SbbW0knAhEJMHq81ncgbKHez3aw7WWx2vgfltcukTotdqf7fJV-XuDECd61wNkKF17JPAEsZNNnyouwdBeca4FwwhCWVcAjLQpI03ZqdUCcCe_Gt5UTmnG1hGBCIHFjPdf5PTWZWstqsa7JJrxKBg=w1824-h1026-s-no)

<br>

### {% label 入住洞爺湖太陽宮飯店(Sun_Palace) purple %}

{% note success no-icon %}
為了躲避外頭的陰雨，全家一心只想直奔飯店休息。途中我們在「きのこ王國（蘑菇王國）」休息站稍作停留採買。抵達飯店後，立刻換上舒適的日式浴衣，在房內品茗日本抹茶，靜靜欣賞窗外的洞爺湖景。雖然因為下雨無法外出散步有些可惜，但在舒適的和式客房裡，看著女兒開心穿梭的模樣，便覺十分愜意。
{% endnote %}

**黃金週的擁擠小插曲**
適逢日本黃金週假期，雖然自駕沿途人車稀少、路況順暢，但飯店餐廳卻是人山人海，光是排隊等候晚餐就花了不少時間。不過，看著隔壁桌的日本客人一口氣狂掃 14 盤握壽司，而我們戰鬥力薄弱只吃了 2 盤，也是晚餐時段的一件趣事。

## 第二天：洞爺湖 — 羊蹄山 — 定山溪

{% note success no-icon %}
早晨拉開窗簾的瞬間，滿滿的感動湧上心頭！揮別昨日的陰霾，迎接我們的是萬里無雲的湛藍晴空。遠處的羊蹄山清晰可見，那份震撼與喜悅難以言喻。我們倚著湖畔的窗邊享用早餐，絕佳的景致讓心情也跟著明朗起來。
{% endnote %}

![第二天清晨晴空萬里](https://lh3.googleusercontent.com/pw/AP1GczM3-R5dSV4tt5sD_cyADdbqUdQRsrUh8-GdU9l1S3ugma9EOy3sCODdVeZiCuUZQimnlNvir-nUqqjNkyN6DxKrKnjR4jh_jmqgDw0ki_FzSAnVO-q55NstKE3uKCCNzS2z1vuPDsE5X0nmAfqh-ALBlA=w1824-h1026-s-no)

### {% label 飯店外湖畔散策 orange %}

吃過早餐後，我們來到飯店外的湖岸邊散步。波光粼粼的湖水與遠山交織成畫，美得讓人捨不得離開，不知不覺就按下了無數次快門。
{% endnote %}

帶著依依不捨的心情離開洞爺湖，今天的行程十分豐富：サイロ展望台、浮見堂公園、真狩村、羊蹄山下公園……出發吧！
{% endnote %}
<br>

### {% label サイロ展望台(Silo展望台) orange %}

{% note info no-icon %}
站在展望台上，不僅能將洞爺湖的全貌盡收眼底，還能將中島、有珠山、昭和新山、洞爺湖溫泉街以及西山火山口等壯麗景致一網打盡。天氣好，怎麼拍都好看，連我們這對老夫老妻都覺得瞬間變年輕了。
{% endnote %}

![サイロ展望台](https://lh3.googleusercontent.com/pw/AP1GczOxY9cC61k_dHPIsvemOIW6qkGzejHilvPAg9xQQw57YIPQ1yqVFtRrCqTS5a5BcbGqZcRaKZ3pgrlji49wk0saffF31m2laUvMJPkFmekgyek70nLDJDGrQ5GshjncU-YfPDXHnNDhAJztIlaaDZXb-w=w1824-h1026-s-no)

### {% label 浮見堂公園 red %}

{% note info no-icon %}
位於洞爺湖北方湖畔的「浮見堂公園」，是一處私房的賞櫻景點。這裡沒有喧囂的商家與擁擠的人潮，只有悠閒散步與露營的人們。湖畔春意盎然、百花盛開，靜謐的氛圍令人身心舒暢。

車才剛停妥，就被停車場周邊盛開的櫻花樹給吸引。依傍著湖畔的櫻花開得極美，我們沒有任何趕路的壓力，就這樣 *ゆっくり散策*（慢慢散步），感受這份自在。
{% endnote %}

### {% label 真狩村(まっかり)河川公園 green %}

{% note info no-icon %}
下一站來到了羊蹄山腳下的真狩村。最初是為了一睹那條筆直通往羊蹄山的壯闊道路而來，卻意外發掘了「真狩村河川公園」這個寶藏景點。光是在車上，就能不斷感受到羊蹄山帶來的視覺震撼。
{% endnote %}

![開在車上也能感受大山的震撼](https://lh3.googleusercontent.com/pw/AP1GczPdvzACPGTiFNAPIK2Dh6NSjdzbtdJbi7_vUXrxtj8w88I4ew4ORa-ppkmxZGdjq6xn8wv1E667ZlOIMRJiuAUOiCK-PDEa1eoXNXKJvgWiFisW2pLgvq_H31zNr1-TJFktzkpOdPt4oaupNsG6Ltp86w=w1824-h1026-s-no)
![直直的通往羊蹄山道路](https://lh3.googleusercontent.com/pw/AP1GczMMbc5-MeCuSQ9LQE_msh5NqpdQtd-20Vg-w0eye1T9wcRi5mlQiQkGeWdGpfsqWqMNygYPyGCVpEw-VX7wNdQAjGZtDR8AM93HW7rqrP36XGjK3-5illlFJbYgGe_LO31z2MmFPzcI3CDG5h0x8vduZA=w1824-h1026-s-no)

{% note success no-icon %}
真狩川上的鯉魚旗隨著微風飄動。儘管已是五月，15 度的氣溫加上從羊蹄山吹拂下來的風，初覺舒爽，吹久了還是會讓人直打哆嗦。這座親水公園設計簡約、綠意盎然，曾獲日本建設大臣獎肯定，重點是免費開放且附有大型停車場，是眺望羊蹄山的絕佳位置。公園內還立有一尊紀念當地出身的國寶級演歌天王——細川貴志的雕像。
{% endnote %}
